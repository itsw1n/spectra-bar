# Saved SPECTRA geometry goal

[Approved reference image](../assets/spectra-bar.png)

Reproduce the reference's layered prism structure while retaining the current 32 logical pixel bar, module layout, native Omarchy widgets, and popup behavior. Keep the Arch logo at the physical center. Future changes should refine this reference rather than substitute a new design.

The central badge uses a compact hexagonal body, a darker inset face, a second fine outline, an ice-blue Arch mark, and small triangular facets joining the shoulders. Neighboring panels use full-height diagonals with shared slopes, a darker inset face, a graphite backing surface, and restrained upper edge accents. Avoid symmetric pointed ends, doubled horizontal outlines, large gaps, glow, and additional bar height.

The reference image is 1920×51. The installed bar is 1920×40 physical pixels on the laptop at 1.25× scale. The geometry is adapted to the required compact height; this is not a claim of identical pixels or identical lighting.

Refinement order: badge → clock/update panel → media panel → utilities → remaining panels. Capture the actual Quickshell render after each stage and assess silhouettes and seams before spreading a new treatment.
